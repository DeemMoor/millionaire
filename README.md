# Миллионер

Настольная экономическая игра на троих (ремейк версии 2001 года) на Flutter.
В приоритете Web и Windows, остальные платформы позже.

## Правила (реализовано)

- Игроки по очереди бросают два кубика и ходят фишками по кругу.
- Свободную фирму можно купить по цене на клетке.
- На чужой фирме платишь ренту: 10% цены, ×2 если у владельца собрана вся группа.
- BANK выдаёт сумму, написанную на клетке.
- Дубль: ещё один бросок.
- Элеватор: стоишь на нём — следующий бросок 2–6 ведёт дальше по кругу,
  7–12 — вниз в шахту (31 → 32 → 33 → 15 000 $ → элеватор).
  Из шахты выход только точным попаданием на элеватор.
- Не хватило на ренту — банкрот, фирмы освобождаются. Последний оставшийся побеждает.

- Start: +20 000 за проход или попадание.
- Treasure: +300 000.
- CRISIS: теряешь 20% наличных.

## Запуск

```sh
flutter test
flutter run -d chrome
flutter build web --wasm --no-web-resources-cdn
node tool/serve.mjs   # http://localhost:8790
```
